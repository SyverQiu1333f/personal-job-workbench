# 个人求职工作台 · 免安装版

适用 Windows 10／11 x64。界面在默认浏览器中打开；无需单独安装 Python、配置命令或下载依赖，基础使用可离线。

## 第一次使用

1. **完整解压 ZIP** 到固定、可写的个人文件夹，例如 `D:\个人工具\求职工作台`。不要直接在压缩包里运行，也不要只复制一个启动文件。
2. 双击 **启动工作台.bat**，会自动打开浏览器；首次启动通常需要几秒钟。
3. 双击 **创建桌面快捷方式.bat**，以后可从桌面双击打开。若桌面已有同名入口，程序会提示且不覆盖，请先重命名旧入口。桌面入口带工作台图标，启动时不显示命令窗口。
4. 结束使用时先在网页保存，然后双击 **关闭工作台.bat**。关闭浏览器不会退出服务；关闭入口只操作本工作区，不会按端口号强制结束其他程序。

首次启动生成自己的空白工作区，不含分享者的岗位、简历、图片或其他求职资料。重复启动复用本工作区，默认端口被占用时自动寻找空闲端口，浏览器地址以启动器打开的为准。

## 文件结构

```text
启动工作台.bat             打开本机浏览器界面
关闭工作台.bat             核对身份后等待保存完成并退出
创建桌面快捷方式.bat       创建本人桌面入口
runtime/                   内附的独立 Python 和全部运行依赖
workbench/                 页面、脚本、PDF 字体和业务代码
data/                      首次启动后生成：数据库、附件、完整备份
run/                       首次启动后生成：服务锁和进程身份
logs/                      首次启动后生成：运行及启动错误
```

请保留整个 `data/`。上传成功的文件已复制到工作台，移动或删除最初的源文件不会影响工作台副本。分享自己的程序给别人时，重新发送原始空白 ZIP；使用过的文件夹会含个人数据。

## 备份和更新

在“导出与备份”创建并下载**完整备份 ZIP**。分析导出包不能用于恢复。建议将完整备份另存到其他磁盘。

更新前先备份并关闭服务，保留旧目录和整个 `data/`。新包不包含 `data`；可以由已授权的 AI 在核对版本、文件差异和备份后更新程序及 runtime，保持数据目录位置不变。不要用空白数据覆盖原资料。若换到新目录，可从完整备份恢复；确认新目录能读取全部资料后，再自行整理旧副本。更新指引见 `docs/AI_UPDATE.md`。

移动文件夹前先关闭服务，移动后重新创建桌面快捷方式，旧快捷方式仍指向旧位置。

## 常见问题

- **没有打开浏览器**：查看 `logs/portable-startup.log` 或 `logs/portable-error.log`；若日志提示服务已启动，可用 `run/port.txt` 中的端口手动访问 `http://127.0.0.1:端口`。
- **提示运行环境缺失**：确认 ZIP 已全部解压，`runtime` 文件夹没有遗漏。此包不能仅发送一个 bat 文件。
- **提示目录不可写**：解压到自己的普通文件夹；不要求管理员权限，不推荐放在 Program Files、临时压缩预览目录或只读目录。
- **关闭需要等待**：程序会等待正在保存的记录或备份完成，不强制杀进程。若提示尚在关闭，稍后再试。
- **打不开 PDF／图片**：原件格式或内容可能损坏，仍可查看具体中文提示与下载原件。

本版只支持本机单人使用，不是公网部署或多人共享服务器。运行环境为随包的 Python 3.12.10；依赖版本见 `requirements-runtime-lock.txt`，第三方许可证随组件保留。包未做商业代码签名；不要求关闭安全软件或降低系统保护。
