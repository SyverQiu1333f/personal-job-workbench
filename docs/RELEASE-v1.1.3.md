## 下载和使用

下载发布资产 **personal-job-workbench-v1.1.3-windows-x64.zip**；GitHub 自动生成的 Source code ZIP 不含运行环境。

1. 完整解压到自己可写的固定目录。
2. 双击“启动工作台.bat”，浏览器自动打开现有工作台界面，无需安装 Python 或依赖。
3. 可双击“创建桌面快捷方式.bat”，以后从桌面打开；结束时先保存，再运行“关闭工作台.bat”。

适用 Windows 10／11 x64。ZIP 约 21MB，包含官方 Python 3.12.10、固定版本运行依赖、本地 PDF.js 及字体。首次运行创建独立空白工作区，不含分享者岗位、简历、图片或配置。每个使用者的数据保存在自己的 data 目录。

## 本次变化

- 增加独立运行环境、启动／关闭／桌面快捷方式入口；源码安装方式仍保留。

- 增加可重建打包脚本、文件哈希清单、发行 ZIP 校验和和免安装版更新说明。
